The grid runs edge to edge now, so there is no aperture to fade against — instead a tilted horizon thins the field toward the top, which is what gives the band its diagonal upper edge rather than a hard cut. Cells stay on a fixed square lattice sized off the plate width, so the ruling reads the same whatever the frame does. Both inks are set by hex — type a code or use the swatch, 3- or 6-digit, hash optional. They colour the plates only, never the interface, so a pale ink cannot make the controls unreadable. Stock sets the ground they print on, and overprint follows it — darkening on pale stock, lightening on dark. The page itself stays light whatever the viewer's theme, and the second plate runs on its own clock, angle and wavelength. Export SVG writes the frame currently on screen as real circles, one group per plate, at the plate's own pixel size — the canvas and the export are generated from a single pass over the grid, so what you save is what you saw. Copy SVG puts the same markup on the clipboard to paste straight into Illustrator or Figma, no download in between. Space pauses.
