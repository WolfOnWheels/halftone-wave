Each plate carries its own clock, screen angle and wavelength, so the two waves drift through each other instead of staying locked. The plate underneath is pulled in front only where its dot is clearly smaller — at 80 % it reads as a ring, and near-equal dots keep a fixed order rather than swapping every frame. The last stretch before the threshold fades in, so the lift arrives without a pop. Screen angle is the direction the wave travels, clockwise from due right, so 315° runs from bottom left up to top right. Set the orange plate to Opposed and it collapses back to the exact inverse of the key plate. Space pauses.
