# Halftone wave

Two animated halftone studies. Each is a single self-contained HTML file —
no build step, no dependencies. Open the file, or view them live:

- **[Interfering screens](https://wolfonwheels.github.io/halftone-wave/circular/)** —
  a circular aperture with two plates running on independent clocks, angles and
  wavelengths, drifting through each other.
- **[Banner screen](https://wolfonwheels.github.io/halftone-wave/banner/)** —
  a full-bleed horizontal grid on white stock, with hex-settable inks and
  SVG export.

Dots sit on a fixed lattice; only their radius animates. A travelling wave is
sampled at each dot centre and mapped to dot area, so a crest reads as solid
mass and a trough falls away to specks.
